# KU SW·AI 과목 탐색기

고려대학교 SW·AI융합대학원 2026학년도 2학기 강의계획서를 구조화한 비공식 공개 카탈로그입니다.

[Vercel에서 기존 GitHub 저장소 Import하기](https://vercel.com/new)

## 주요 기능

- 19개 과목의 요일·교시별 미니 시간표와 학교 게시 원본 시간표
- 학과, 요일, 교시, 수업 방식 필터
- 과목명, 학수번호, 교수명, 주제 검색
- 강의 개요, 학습 목표, 평가, 과제, 주차별 계획 상세 보기
- 공식 전임교원 페이지에서 확인한 교수 프로필 사진
- 최대 3개 과목 비교
- 비교 과목 시간 충돌 경고
- 강의계획 불일치가 있는 과목의 확인 메모
- 모바일 반응형 화면

## 로컬 실행

`index.html`을 더블클릭해 `file://` 주소로 열어도 실행됩니다.

정적 파일 서버로 실행하려면 다음 명령을 사용할 수도 있습니다.

```bash
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## GitHub Pages 배포

저장소 Settings의 Pages에서 배포 소스를 `Deploy from a branch`로 선택하고, `main` 브랜치의 `/ (root)`를 지정하면 됩니다.

## 데이터 원칙

- 교수 개인 전화번호는 공개하지 않습니다.
- 강의계획서 원문 전체를 재배포하지 않고 검색·비교에 필요한 정보를 구조화합니다.
- 내부 데이터에는 자료 범위를 기록하되 사용자 화면에는 불필요한 완성도 등급을 표시하지 않습니다.
- 공식 정보와 상세 강의계획이 충돌하면 `conflict`로 표시합니다.
- 실제 수강 정보는 고려대학교 공식 시스템에서 다시 확인해야 합니다.
